## 5. What's included

- A custom website on the proven Casa Aurelia template, configured to your brand
  and content
- Online reservations, dynamic menu, and admin dashboard (per package)
- Responsive, multilingual, mobile-optimized, SEO-ready build
- Browser-based testing and your review round with corrections
- Deployment to your hosted domain (or hosting included per package)
- Basic guidance on keeping the menu updated via the admin dashboard

## 6. What's not included

- **Content creation** — your photos, menu text, and translations (we can guide,
  and photo guidance is an optional extra). We build from the content you provide.
- **Online payments** — taking deposits/payments is not part of this scope.
- **Staff accounts / roles** — the admin is a single owner login (the roadmap adds
  staff roles later, not in this build).
- **A custom CMS or multi-restaurant (SaaS) platform** — each restaurant gets its
  own site; a shared platform is a later phase.
- **Domain registration** unless hosted by us (then we'll register it for you).
- Anything not listed in "What's included."

---

## 7. Hosting & maintenance

The website runs on modern, reliable hosting with daily backups and security
updates (per package). Ongoing care can include menu updates, content changes,
bug fixes, and technical support. If you prefer to manage the menu yourself,
you'll be able to via the admin dashboard — no developer needed for daily changes.
